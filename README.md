# ربات مدیریت مرزبان (تک ادمین)

یک ربات تلگرام برای مدیریت کاربران پنل Marzban فقط توسط خودت (بدون کاربر یا نماینده‌ی دیگه، بدون پرداخت).

## قابلیت‌ها
- افزودن کاربر جدید (با تعیین حجم و مدت اعتبار)
- لیست و مشاهده‌ی جزئیات کاربران
- افزودن روز / افزودن حجم به کاربر موجود
- ریست مصرف کاربر
- فعال/غیرفعال کردن کاربر
- حذف کاربر
- دریافت لینک اشتراک (subscription link)
- وضعیت کلی سیستم (تعداد کاربران، مصرف، منابع سرور)

## پیش‌نیازها
1. یک ربات تلگرام از [@BotFather](https://t.me/BotFather) بساز و توکنش رو بردار.
2. آیدی عددی تلگرام خودت رو از [@userinfobot](https://t.me/userinfobot) بگیر.
3. آدرس سرویس پنل مرزبانت روی Railway (همون که فورک کردی)، مثلاً:
   `https://your-panel-service.up.railway.app`
4. یوزرنیم و پسورد ادمین سودو پنل (همونی که با `SUDO_USERNAME` / `SUDO_PASSWORD`
   ست کردی یا با `marzban-cli admin create --sudo` ساختی).

## متغیرهای محیطی (Environment Variables)

| نام | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_ID` | آیدی عددی تلگرام خودت |
| `MARZBAN_URL` | آدرس کامل سرویس پنل، بدون `/` انتهایی |
| `MARZBAN_USERNAME` | یوزرنیم ادمین سودوی پنل |
| `MARZBAN_PASSWORD` | پسورد ادمین سودوی پنل |

## اجرا روی Railway (پیشنهادی، چون پنل و نودت هم آنجاست)

1. این پوشه رو به یک ریپوی گیت‌هاب جدید پوش کن (یا در همون ریپوی پنل، به‌عنوان یک زیرپوشه/سرویس جدا).
2. در همون پروژه‌ی Railway که پنل و نود توش هست، گزینه‌ی **New → GitHub Repo** رو بزن و این ریپو رو انتخاب کن.
3. متغیرهای بالا رو در تب **Variables** ست کن.
4. چون این یک ربات با polling هست (نه وب‌سرویس)، نیازی به دامنه یا پورت نداره؛ Railway به‌صورت پیش‌فرض به‌عنوان یک process اجراش می‌کنه.
5. Deploy کن و منتظر بمون تا build تموم بشه؛ بعد به ربات توی تلگرام دستور `/start` رو بزن.

## اجرای محلی (برای تست)

```bash
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt

export BOT_TOKEN="xxxx"
export ADMIN_ID="123456789"
export MARZBAN_URL="https://your-panel.up.railway.app"
export MARZBAN_USERNAME="admin"
export MARZBAN_PASSWORD="yourpassword"

python bot.py
```

## نکات مهم امنیتی
- ربات فقط به آیدی عددی `ADMIN_ID` جواب می‌ده؛ هر کس دیگه‌ای پیام بده، رد می‌شه.
- توکن ربات و پسورد پنل رو هیچ‌وقت داخل کد ننویس؛ فقط از طریق Environment Variables ست کن.
- اگه توکن ربات یا پسورد پنل لو رفت، فوراً از BotFather (دستور `/revoke`) و از پنل مرزبان (تغییر پسورد ادمین) عوضشون کن.

## ساختار پروژه
```
marzban_bot/
├── bot.py            # هندلرهای اصلی و منطق ربات
├── marzban_api.py     # کلاینت API مرزبان
├── keyboards.py       # دکمه‌های اینلاین
├── states.py          # وضعیت‌های مکالمه (FSM)
├── config.py           # خواندن متغیرهای محیطی
├── requirements.txt
└── railway.toml
```

## گسترش‌های بعدی که راحت می‌تونی اضافه کنی
- ارسال هشدار خودکار وقتی حجم یا زمان کاربری رو به اتمامه.
- بک‌آپ‌گیری خودکار از دیتابیس پنل.
- ساخت گزارش روزانه/هفتگی از مصرف کلی.
