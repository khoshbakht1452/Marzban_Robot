# ربات مدیریت مرزبان (چند ادمین)

یک ربات تلگرام برای مدیریت کاربران پنل Marzban، با پشتیبانی از چند ادمین، هشدار خودکار، و بک‌آپ روزانه.

## قابلیت‌ها
- افزودن کاربر جدید (با تعیین حجم و مدت اعتبار)
- لیست کاربران با نمایش وضعیت آنلاین/آفلاین هر کدوم
- جزئیات هر کاربر: مصرف با نوار پیشرفت، آخرین اتصال، تاریخ انقضا
- افزودن روز / افزودن حجم به کاربر موجود
- ریست مصرف کاربر
- فعال/غیرفعال کردن کاربر
- حذف کاربر (با تایید)
- دریافت لینک اشتراک (subscription link)
- وضعیت کلی سیستم (تعداد کاربران، مصرف، منابع سرور)
- **چند ادمین**: هر تعداد آیدی تلگرام که بخوای می‌تونن هم‌زمان با بات کار کنن
- **هشدار خودکار**: هر ساعت چک می‌کنه و اگه کاربری بیش از ۹۰٪ حجمش تموم شده یا کمتر از ۲۴ ساعت به انقضاش مونده، به همه‌ی ادمین‌ها پیام می‌ده
- **بک‌آپ روزانه**: هر روز ساعت ۳ بامداد (UTC) یه فایل JSON از کل لیست کاربران (نه بک‌آپ کامل دیتابیس) برای ادمین‌ها می‌فرسته

## پیش‌نیازها
1. یک ربات تلگرام از [@BotFather](https://t.me/BotFather) بساز و توکنش رو بردار.
2. آیدی عددی تلگرام همه‌ی ادمین‌ها رو از [@userinfobot](https://t.me/userinfobot) بگیر.
3. آدرس عمومی سرویس پنل مرزبانت روی Railway، مثلاً:
   `https://your-panel-service.up.railway.app`
4. یوزرنیم و پسورد یک ادمین سودو پنل (با دستور `python marzban-cli.py admin create --sudo` از کنسول سرویس پنل ساخته می‌شه).

## متغیرهای محیطی (Environment Variables)

| نام | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_IDS` | آیدی‌های عددی همه‌ی ادمین‌ها، با کاما جدا از هم (مثلاً `111111,222222`) |
| `MARZBAN_URL` | آدرس کامل سرویس پنل با `https://` و بدون `/` انتهایی |
| `MARZBAN_USERNAME` | یوزرنیم ادمین سودوی پنل |
| `MARZBAN_PASSWORD` | پسورد ادمین سودوی پنل |

## اجرا روی Railway

1. این پوشه رو به یک ریپوی گیت‌هاب جدید پوش کن (با GitHub Desktop یا آپلود مستقیم، با حفظ ساختار پوشه‌ها).
2. توی پروژه‌ی Railway، گزینه‌ی **+ Add → GitHub Repo** رو بزن و این ریپو رو انتخاب کن.
3. متغیرهای بالا رو در تب **Variables** ست کن.
4. چون این یک ربات با polling هست (نه وب‌سرویس)، نیازی به دامنه یا پورت نداره.
5. صبر کن Deploy تموم بشه، بعد توی تلگرام دستور `/start` رو بزن.

## اجرای محلی (برای تست)

```bash
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt

export BOT_TOKEN="xxxx"
export ADMIN_IDS="123456789,987654321"
export MARZBAN_URL="https://your-panel.up.railway.app"
export MARZBAN_USERNAME="admin"
export MARZBAN_PASSWORD="yourpassword"

python bot.py
```

## نکات مهم امنیتی
- ربات فقط به آیدی‌های داخل `ADMIN_IDS` جواب می‌ده؛ هر کس دیگه‌ای پیام بده، رد می‌شه.
- توکن ربات و پسورد پنل رو هیچ‌وقت داخل کد ننویس؛ فقط از طریق Environment Variables ست کن.
- اگه توکن ربات یا پسورد پنل لو رفت، فوراً از BotFather (دستور `/revoke`) و از پنل مرزبان (تغییر پسورد ادمین) عوضشون کن.

## ساختار پروژه
```
marzban_bot_v2/
├── bot.py            # هندلرهای اصلی، منطق ربات، هشدار خودکار و بک‌آپ
├── marzban_api.py    # کلاینت API مرزبان
├── keyboards.py       # دکمه‌های اینلاین
├── states.py          # وضعیت‌های مکالمه (FSM)
├── config.py           # خواندن متغیرهای محیطی
├── requirements.txt
└── railway.toml
```

## تنظیمات قابل تغییر هشدار/بک‌آپ
اگه خواستی آستانه‌ها یا زمان‌بندی رو عوض کنی، این متغیرها بالای `bot.py` هستن:
- `DATA_ALERT_THRESHOLD` (پیش‌فرض `0.9` یعنی ۹۰٪)
- `EXPIRE_ALERT_HOURS` (پیش‌فرض `24` ساعت)
- `BACKUP_HOUR_UTC` (پیش‌فرض `3`)
- `ALERT_CHECK_INTERVAL` (پیش‌فرض هر ۳۶۰۰ ثانیه/۱ ساعت)

## گسترش‌های بعدی که راحت می‌تونی اضافه کنی
- نود دوم برای مولتی‌لوکیشن و پخش بار
- قالب کاربری پیش‌فرض (User Template) در خود پنل
- جستجوی کاربر با اسم توی بات
